# ⏰ Alberto Clock

 **Alberto Clock** is a simple, elegant, and user-friendly digital clock project designed to display the current time with a clean and modern interface.

 ## ✨ Features

 - 🕐 Real-time clock display
- 🎨 Clean and modern UI
- 📱 Responsive design
- ⚡ Lightweight and fast
- 🔄 Automatically updates the time
- 🌐 Works directly in the browser

 ## 🛠️ Technologies Used

 - HTML5
- CSS3
- JavaScript
